### 已确认的 Mathlib 事实（`#check` 实测 + 读源码）

- `Mathlib.SetTheory.Ordinal.Notation`（1297 行，Carneiro）：`ONote`/`NONote` + `ONote.fastGrowing`，值域 `< ε₀`。
  `fastGrowing` 靠 `InvImage.wf repr Ordinal.lt_wf` 递归 ⇒ 结构上进不了 ε₀。
- `ONote.fastGrowingε₀ : ℕ → ℕ` 是**外部 hack**（`(fun a => a.oadd 1 0)^[i] 0`），不在 `fastGrowing` 类型里，只有 3 条值定理（1/2/2048）。
- **整个 Mathlib 只有 `Mathlib.lean` import `Notation.lean`**（`Veblen.lean` 同理）⇒ FGH 是孤岛，改起来没人会被波及。
- `Veblen.lean` 已有 `veblen`、`epsilon`(ε_/ε₀)、`gamma`(Γ_/Γ₀)、`invVeblen₁/₂`；
  `veblen_invVeblen₁_invVeblen₂ : veblen x.invVeblen₁ x.invVeblen₂ = ω ^ x`，注释明说"配 CNF 给出 Γ₀ 以下的 predicative notation"。
  文献引的是 Miller 1976（JSL 41:439–459）。
- **ε₀ 的 FS 原料已存在**：`Ordinal.lt_epsilon_zero : o < ε₀ ↔ ∃ n, o < (ω^·)^[n] 0`（就是 ω-塔共尾性）；
  `iterate_omega0_opow_lt_epsilon_zero`；`IsFundamentalSeq.comp_isNormal`（FS 穿过正规函数的 transport）。
- `FundamentalSequence.lean` 的 `IsFundamentalSeq` 是**非构造**存在性，拿不到 `ℕ → Term`，对 FGH 无用。
- ⚠️ **Mathlib 没有任何定理把 `ONote` 值域和 ε₀ 连起来**（grep 全目录只命中文档注释）⇒ 连 `repr o < ε₀` 都没证。
- `IsNormal` 在**根命名空间**，不是 `Ordinal.IsNormal`（踩过）。
- `IsSuccLimit a` = `{not_isMin; isSuccPrelimit}`；判据 `isSuccLimit_iff` + `isSuccPrelimit_iff_succ_lt`。
- 旁边有 `Mathlib.Logic.Hydra`（TODO 明说 Kirby–Paris/Buchholz 待做）、`Computability/Ackermann`、`Computability/Primrec/Basic`。
