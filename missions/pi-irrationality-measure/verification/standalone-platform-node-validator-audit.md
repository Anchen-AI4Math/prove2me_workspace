# Standalone node validator audit — 2026-10-08

Implemented `scripts/validate_standalone_platform_node.py`. This is a local
validator and has no publish API, network operation, or full-tree readiness
transition. This agent did not run Lean.

Supported boundary: one unchanged public ordinary source theorem, with optional
same-file unchanged public atomic inline theorem commands. Definitions, child
nodes, renames, local instances, cross-file components, and missing project
kernel dependencies are rejected. Compiler-generated dependencies without an
actual retained theorem command are also rejected; no parent identity is
inferred from their spelling.

Before compilation, it checks the manifest's complete global input hash set,
original and port source hashes, selected AST facts, graph, runtime, snapshot
core and generator hashes. It reloads and recomputes the current plans through
the existing generator and captures all four generator outputs in memory.
Every manifest field affecting generated text, and every generated byte, must
match this reconstruction. No generator output is rewritten by this check.
Actual retained source command spans must equal the selected inline/helper
command spans; their full graph closure must have no missing project constant.

The extraction-state hash remains a strict global pin. New completed extraction
entries invalidate an old manifest even when the selected facts are unchanged.
Hold extraction, refresh all inventories/plans, regenerate the selected node,
then validate it. This validator does not implement a weaker selected-facts
exception to stale global planning inputs.

The executing path compiles Thm, Sol, original snapshot and generated snapshot
through `preflight_logged.py --verification --timeout-seconds 300`, checks each
fresh result and log SHA, removes old snapshot JSON before compiling, compares
source/target/solution kernel types with only universe parameter display-name
normalization, and requires source and both solution axiom audits to be subsets
of `[propext, Classical.choice, Quot.sound]`. Generated solution kernel project
references must be provided by actual inline declarations. Implementation,
runtime, global inputs and source witnesses are rechecked before certification.

Success sets this exact node's `validated` and `local_standalone_validated` to
true. Its `provisional` flag remains unchanged; `submission_ready` remains false,
and the certificate explicitly records `full_tree_ready: false`.

Pure Python QA passed:

- Real `log_norm_sum_le` `--check-only` passed. Its complete project kernel

The real checks performed no Lean compilation and wrote no node files. Root
will run the four-file compilation and kernel/axiom certification separately.
