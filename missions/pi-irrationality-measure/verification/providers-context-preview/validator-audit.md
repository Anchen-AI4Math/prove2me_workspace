# Isolated context source/provider existing-evidence validation

`scripts/validate_namespace_context_providers.py` never starts Lean or network
requests and does not edit the ordinary checker or frozen context generator.
The original34 source exporter, its successful 40.15155-second record, output
and logs are reused by exact hashes. The current source34 certificate remains
partial, not platform-ready, and is not a full6148 kernel certificate. All6148
owner rows are metadata; only the requested34 CIs have actual source evidence.

The checker freshly rebuilds the original provider promotion/artifact plans,
recomputes the AST-owned namespace overlay without writing it, and checks all
four exact output bodies against independent declaration/import edits. It
refuses any private, rename, instance, mixed structural or extra-helper case.
Original/generated request domains and full-catalog owner rows are recomputed.

Every actual record requires exact source/manifest/ordered import identities,
runtime/executable/project pins, input maps, source certificates, log SHA and
stable first-path OLean resolution. Each run must be <=300 seconds. JSONL output
must fall within the actual record's execution window. Public CI rows require
exact graph Name/row/command/module identity, structural closedness and unique
universe binders. Safe ordinary definitions export complete nonnull values;
theorem proof values are null. Axioms must lie in Std3.

Windows normalization uses the existing narrow cache helper. Only OLean `path`
and `resolved_search_root` may differ in drive-letter case; suffixes must match
exactly and `Path.samefile` must identify the same existing object. The checker
explicitly supports the four-field fast witness and six-field runner witness
schemas; it does not ignore arbitrary extra fields or hash changes.

Four emit-olean runs are bound before preparing the generated group, together
with fresh live revalidation of the external PolynomialFrameDegree provider.
`generated-snapshot/SnapshotGeneratedContextFast.lean` imports Lean and those
four actual generated modules. Its public lookup/export logic matches the
source34 snapshot; it checks actual owner, closed type/full Def value and Std3.
The group is 34 requests, preserving each source/target owner separately.

`--certify-existing` compares every generated structural type and ordinary Def
value against source34, permitting only universe binder-name normalization.
It also compares kind/safety and exact Std3 axiom sets. It writes one independent
`context-provider-validation.json` per module. The read-only publisher API
`validate_context_provider(module)` recomputes the complete evidence and checks
those exact certificates, returning the frozen raw source bytes. No metadata
flag alone supplies a declaration or proves a type/value correspondence.
