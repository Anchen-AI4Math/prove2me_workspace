Set $\gamma=s/2$. The parameter $g$ lies between $D^\gamma$ and $2D^\gamma$. Consequently $g/D^s\le 2D^{-\gamma}$ and $1/g\le D^{-\gamma}$. Since $s\le 1/2$, the query and answer-reading factors satisfy $gD^{1/2-s}/\sqrt D\le2D^{-\gamma}$ and $g/\sqrt D\le2D^{-\gamma}$. Finally $D^{1+s}\le n$ implies $gD\le2nD^{-\gamma}$.

These are elementary real-power inequalities. They balance the five factors of the full-dimension host without assuming an additional algorithm or runtime bound. The complete Lean proof uses only standard axioms.
