Research notes and reproducible finite certificates for the existing
[ζ(9) weighted-lattice mission](https://prove2.me/missions/Irrationality_of_%CE%B6%289%29%3A_weighted_lattice_route).

**The irrationality goal remains unproved.** This archive contains written mathematical results,
independent reviews and bounded exact/Arb verification. Recent research has not been checked in Lean.

Start with `PACKAGE-README.md`, then `missions/zeta9/README.md` and `PUBLIC_OVERVIEW.md` in the ZIP.
`source-manifest.json` records every included file's SHA-256 and package boundaries.
`reproduction-report.json` records the independent extracted-package replay of the latest five groups.

Current contributions include a new Gram gcd divisor, exact least-denominator same-side projections,
an exponential error squeeze for a growing-dimensional positive linear family, a complete scalar
dispersed-pole classification, and an isolated rational sum with an exact endpoint-leakage repair.
Each note states its unresolved infinite input; finite small values are not presented as a proof.

The release uses the task's existing public research repository. It does not replace or rewrite its
previous source tree. The package preserves original research paths and certificate bytes, contains
the actual dependencies needed for replay, and excludes credentials, caches and third-party paper copies.
