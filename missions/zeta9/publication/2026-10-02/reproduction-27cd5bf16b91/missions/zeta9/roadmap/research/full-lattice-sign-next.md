# 完整像格的鞍点局部定号准则与两条有限负和证书

本笔记把[单形式半轴定号准则](shape-or-j-next.md)弱化为**鞍点附近的取样定号**，并对第七轮冻结的 `n=24,192` 完整像格第一 Gauss 行给出严格的有限负和证书。局部准则尚未在无穷多个参数上验证，因此这里不声称证明 `ζ(9)` 无理，也不更改 DAG 或平台状态。

## 正核、鞍点和归一化多项式

沿用 `u(k)=k(k+n)`、`u₀=(n+1)(2n+1)`、`E_n=SF_n⁻¹`。任取整数输出 `z≠0`，写

\[
 P_{n,z}(u)=\sum_{r=0}^4w_ru^r,\quad w=zE_n,\qquad
 q_{n,z}(y)=P_{n,z}(n^2y)=\sum_{r=0}^4c_ry^r,\quad c_r=w_rn^{2r}.
\]

因此 `‖c‖₂=‖zE_n‖_{n,2}`。第七轮的正核和相位是

\[
 R_n(k)=n!^7\frac{((k-1)!)^{10}(k+2n)!}
 {(k-n-1)!((k+n)!)^{10}}>0,\quad
 f(x)=10x\log x+(x+2)\log(x+2)-(x-1)\log(x-1)-10(x+1)\log(x+1).
\]

记 `x_*` 为 `f` 在 `x>1` 的唯一全局极大点，`f_*=f(x_*)`。已有的[第七轮解析证明](../../round7/research/analytic.md)给 `f_*<−τ`，`τ=2641/250=10.564`。直接求导得

\[
 f'(x)=\log\frac{(x+2)x^{10}}{(x-1)(x+1)^{10}},\qquad
 f''(x)=\frac{10}{x(x+1)}+\frac1{x+2}-\frac1{x-1}.
\]

精确有理交叉相乘显示 `f'(10029/10000)>0`、`f'(10031/10000)<0`；第七轮的唯一极大性于是给
`10029/10000<x_*<10031/10000`，约为 `1.002976465754898`，且 `f''(x_*)<0`。取任意固定 `A>0`，置 `h_n=A n^{-1/3}`。

## 统一取样定号引理

**Z9.SP（鞍点取样定号引理，笔记已证）。** 对任意**预先固定**的 `A>0`，存在只依赖于 `A` 的 `n_A`，使每个偶数 `n≥n_A` 和每个非零实系数四次以下多项式 `q(y)` 满足下述蕴含：如果所有 `k>n` 且 `|k/n−x_*|≤h_n` 的数

\[
 q\bigl(k(k+n)/n^2\bigr)
\]

均弱同号，则

\[
 \sum_{k>n}R_n(k)q\bigl(k(k+n)/n^2\bigr)\ne0,
\]

且该和与局部取样的非零值同号。允许局部某些取样为零；非零四次多项式在不同取样点至多有四个零值，因此五个相邻的中心取样不能同时为零。一个更方便的充分条件是 `q(x(x+1))` 在实区间 `|x−x_*|≤h_n` 上弱同号。

**证明。** 以下常数可依赖 `A`，但不依赖 `q`。先对 `n+1≤k≤10n` 使用统一的阶乘估计 `\log(m!)=m\log m-m+O(\log(n+1))` (`0≤m≤12n`，约定 `0\log0=0`)。原式中 `n\log n` 和线性项精确消去，因而

\[
 \log R_n(k)=nf(k/n)+O(\log n) \qquad(n+1≤k≤10n), \tag{1}
\]

误差常数对整个区间统一。`f` 在 `x_*` 处严格取唯一最大值且 `f''(x_*)<0`。紧区间 `[1,10]` 上的连续性遂给某个 `c>0`，对所有充分大 `n`，

\[
 |x-x_*|>h_n\quad\Longrightarrow\quad
 f(x)≤f_*-c h_n^2=f_*-cA^2n^{-2/3}. \tag{2}
\]

设 `C_q=Σ_{r=0}^4|c_r|≤√5‖c‖₂`。当 `k≤10n` 时，`y=k(k+n)/n²≤110`，故 `|q(y)|≤110^4C_q`。由 (1)–(2)，该有限区间中鞍点窗外的绝对和至多

\[
 \exp\{nf_*-cA^2n^{1/3}+O(\log n)\}\,‖c‖_2. \tag{3}
\]

还须控制 `k→∞`。直接约去相邻阶乘得到

\[
 \frac{R_n(k+1)}{R_n(k)}
 =\left(\frac{k}{k+n+1}\right)^{10}\frac{k+2n+1}{k-n}. \tag{4}
\]

若 `k≥10n` 且 `n≥2`，则 `(k+2n+1)/(k-n)≤1+4n/k≤((k+n+1)/k)^5`；故 (4) 至多为 `(k/(k+n+1))^5`。写 `t_k=(k+n+1)/(11n+1)≥1`，乘积比较及 `\log(1+s)≥s/(1+s)` 给

\[
 R_n(k)≤R_n(10n)t_k^{-5(n+1)}. \tag{5}
\]

又 `y≤144t_k²`，所以 `|q(y)|≤144^4 C_qt_k^8`。用积分比较，

\[
 \sum_{k≥10n}t_k^{-(5n-3)}
 ≤1+\frac{11n+1}{5n-4}≤3n. \tag{6}
\]

因为 `f(10)<f_*`，(1)、(5)–(6) 说明无穷尾和也被 (3) 的右侧控制，必要时缩小 `c`。这一步没有以有限截断代替无穷和。

另一方面，取 `k_i=⌊nx_*⌋+i` (`0≤i≤4`)；充分大时五点都在鞍点窗内。令 `y_i=k_i(k_i+n)/n²`，则这些点在一个固定紧区间，且

\[
 y_j-y_i=(j-i)(k_i+k_j+n)/n²≥2(j-i)/n\quad(j>i).
\]

Lagrange 插值的五个分母各至少为常数乘 `n^{-4}`，分子多项式的系数一致有界。因此存在绝对常数 `C_0`，使

\[
 ‖c‖_2≤C_0 n^4\max_{0≤i≤4}|q(y_i)|. \tag{7}
\]

这还证明非零 `q` 不可能使五点全为零。(1) 和 `k_i/n=x_*+O(1/n)` 给 `R_n(k_i)≥\exp\{nf_*-O(\log n)\}`。因窗内每个取样弱同号，窗内整个和的绝对值至少是 (7) 中一个非零项的绝对值，即

\[
 |\text{窗内和}|≥\exp\{nf_*-O(\log n)\}\,‖c‖_2. \tag{8}
\]

式 (3) 比 (8) 小一个 `\exp\{-cA²n^{1/3}+O(\log n)\}` 因子，最终严格小于它。故窗外任何异号项均不能抵消窗内和。□

**更窄窗口的统一加强。** 上述论证实际只需要一列预先规定的正数 `h_n` 满足

\[
 h_n\to0,\qquad \frac{nh_n^2}{\log n}\to\infty. \tag{8a}
\]

式 (2)–(3) 的窗外损失改为 `\exp\{-cnh_n^2+O(\log n)\}`；(8a) 保证它趋零。又 (8a) 蕴含 `nh_n→∞`，故五个中心相邻取样最终仍在窗内，(7)–(8) 不变；`k≥10n` 的无穷尾估计也不变。因此 Z9.SP 对任何满足 (8a) 的窗口同样成立。特别地，**任意预先固定的 `A>0`** 都可取

\[
 h_n=A\frac{\log n}{\sqrt n},
 \qquad\text{或}\qquad h_n=A n^{-\alpha}\ (0<\alpha<1/2). \tag{8b}
\]

这个加强仍不覆盖任意小 `A` 的临界窗口 `A\sqrt{\log n/n}`，因为那时窗外损失与插值的多项式成本同为 `\log n` 级，现有论证需要额外常数比较。

**Z9.TS（完整格的无穷符号目标，开放）。** 若存在某个**预先固定**的 `A>0`，使无穷多个充分大的偶数 `n` 的完整像格 `Z²E_n` 有一个第一极小输出 `z_n`，其 `q_{n,z_n}(x(x+1))` 在 `|x−x_*|≤A(\log n)/\sqrt n` 的所有实际取样上弱同号，则 `ζ(9)` 无理。证明：`E_n` 行秩二，所以 `q_{n,z_n}≠0`；加强的 Z9.SP 先给 `L_n(z_nE_n)=b_n+a_nζ(9)≠0`。已证[逆像面积界](inverse-area-rate.md)及二维 Hermite 界给 `limsup n^{-1}\log‖z_nE_n‖_{n,2}<γ<τ`，第七轮的统一解析上界遂使 `L_n(z_nE_n)→0`。若 `ζ(9)=c/d∈Q`，这些非零数乘固定分母 `d` 是非零整数，不可能趋零。实际上第一极小可换成任何满足 `‖z_nE_n‖_{n,2}≤e^{(τ-ε)n}` 的整数输出，其中 `ε>0` 固定。此判据比全部 Taylor 系数同号、甚至比整个半轴无根弱；它的无限次符号前提仍开放。

**有理性假设下的精确必要条件。** 若反设 `ζ(9)=c/d` 且 `(c,d)` 为固定互素整数，则固定整数输出 `z_*=(-c,d)` 对每个 `n` 都有严格零和。由加强的 SP 的逆否命题，对每个固定 `A>0`，全部充分大偶数 `n` 的多项式 `q_{n,z_*}(x(x+1))` 必须在 `|x−x_*|≤A(\log n)/\sqrt n` 的**实际取样点**同时取正值和负值；弱同号会导致零和不可能。因此中间值定理给出该窗口内一个实根 `x_n`。令 `d_n^*` 为这些实根到 `x_*` 的最小距离，则对任意固定 `A>0` 最终有 `d_n^*≤A(\log n)/\sqrt n`，从而 `d_n^*=o((\log n)/\sqrt n)`。这只是有理性所迫使的鞍点根集聚，并未证明它与实际连接矛盾。

## 两个完整格第一行的有限负和证书

从冻结的[第七轮模数扫描](../../round7/verification/modulus-scan.json)读取 `n2r`、`full_N` 的第一条 `gauss_reduced_rows`，记其整数系数为 `a_{r,n}`。由[单形式笔记](shape-or-j-next.md)的 Smith 恒等式，实际完整像格的第一向量多项式为正标量 `(D_n/s_{2,n})Σ_ra_{r,n}u^r`，所以只需判断整数多项式 `P_n(u)=Σ_ra_{r,n}u^r` 的正和符号。这里 `n=24,192` 的有限数据如下；小数只定位根，严格证书在表后。

| `n` | `K`，首个可能反号取样 | 端点后实根的 `x=k/n` 有理夹区间 | 根的数值约 | `x_*` 的数值约 | `A=1/2` 的窗半径约 |
|---:|---:|:---:|---:|---:|---:|
| 24 | 49 | `(2,21/10)` | `2.02354016646` | `1.00297646575` | `0.17334032` |
| 192 | 226 | `(117/100,59/50)` | `1.17526782195` | `1.00297646575` | `0.08667016` |

有理端点的多项式值异号；已有精确 Sturm 检查证实各有且仅有一个 `u≥u₀` 实根。`n=192` 的根还能严格夹在 `(11752/10000,11753/10000)`。与 `10029/10000<x_*<10031/10000` 及立方整数比较合用，得到该根与 `x_*` 的距离**小于** `192^{-1/3}≈0.17334032`，所以它落在 `A=1` 的连续窗口里；`A=1/2` 时两例的根都在窗外。有限窗口图像不能推出无穷判据。

下面给出比根定位更强的**实际正和非零证书**。两例均逐项作精确整数比较，得到

\[
 P_n(k(k+n))<0\quad(n+1≤k<K),\qquad
 C_n:=\sum_{r=0}^4|a_{r,n}|n^{2r}<|P_n(u₀)|, \tag{9}
\]

以及用 (4) 的纯有理连乘得到

\[
 \frac{R_n(K)}{R_n(n+1)}
 =\prod_{k=n+1}^{K-1}
 \frac{k^{10}(k+2n+1)}{(k-n)(k+n+1)^{10}}
 <10^{-30}. \tag{10}
\]

这些是可从归档五个整数系数复算的精确不等式，不使用 `ζ(9)` 的数值。为界定 `k≥K` 的所有可能正项，先注意 `R_n(k)` 在 `k≥K` 递减。`n=24` 有 `K≥2n`；对 `k≥2n`，(4) 的最后因子至多 `1+(6n+2)/k`，而 `((k+n+1)/k)^{10}≥1+10(n+1)/k`。`n=192` 的 `K≤k<2n` 上，(4) 至多 `(2/3)^{10}(611/34)<1`；之后用同一个 `k≥2n` 比较即可。

从仓库根目录运行下列只读整数程序，可重算 (9)–(10) 及根夹区间的端点符号；它不采用浮点数，也不截断正和：

```python
import json
from fractions import Fraction

data = json.load(open("missions/zeta9/round7/verification/modulus-scan.json"))
for n, K, ends in [(24, 49, (Fraction(2), Fraction(21, 10))),
                   (192, 226, (Fraction(11752, 10000), Fraction(11753, 10000)))]:
    case = next(c for c in data["cases"] if int(c["n"]) == n)
    mode = next(m for m in case["modes"] if m["mode"] == "n2r")
    tier = next(t for t in mode["tiers"] if "full_N" in t["labels"])
    a = list(map(int, tier["gauss_reduced_rows"][0]))
    P = lambda u: sum(a[r] * u**r for r in range(5))
    u0 = (n + 1) * (2*n + 1)
    C = sum(abs(a[r]) * n**(2*r) for r in range(5))
    assert P(u0) < 0 and C < -P(u0)
    assert all(P(k*(k+n)) < 0 for k in range(n+1, K))
    ratio = Fraction(1)
    for k in range(n+1, K):
        ratio *= Fraction(k**10 * (k+2*n+1), (k-n) * (k+n+1)**10)
    assert ratio < Fraction(1, 10**30)
    assert P(n*n*ends[0]*(ends[0]+1)) < 0
    assert P(n*n*ends[1]*(ends[1]+1)) > 0
```

对于 `K≤k<10n`，有 `|P_n(u(k))|≤110^4 C_n`，故此段绝对和小于 `10n·110^4 C_nR_n(K)`。对 `k≥10n`，上面 (5)–(6) 的证明给绝对和至多 `3n·144^4 C_nR_n(10n)≤3n·144^4 C_nR_n(K)`。因此

\[
 \sum_{k≥K}R_n(k)|P_n(u(k))|
 ≤n(10\cdot110^4+3\cdot144^4)C_nR_n(K)
 <3\cdot10^9n C_nR_n(K). \tag{11}
\]

两例都满足 `n≤192`；由 (9)–(11)，(11) 严格小于 `|P_n(u₀)|R_n(n+1)`。`k=n+1` 的负项单独就压过 `k≥K` 的整个绝对尾和，`n+2≤k<K` 又全为负。因此

\[
 \boxed{\quad\sum_{k>n}R_n(k)P_n(k(k+n))<0
 \qquad(n=24,192).\quad} \tag{12}
\]

正标量 `(D_n/s_{2,n})` 不改变此结论。这说明半轴上有一个实根的最短方向，仍可以有严格可证的非零线性形式；两个有限证书本身不构成 `ζ(9)` 无理性证明。
